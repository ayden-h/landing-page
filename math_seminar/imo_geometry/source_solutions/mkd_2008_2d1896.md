## Supplied solution 1

From the condition in the problem we have that $\beta = 2\alpha$ and $\beta = \delta - 40^\circ$. From this we have $\delta = 2\alpha + 40^\circ$. Because $ABCD$ can be inscribed in a circle we have that $\alpha + \gamma = \beta + \delta$ and because $\alpha + \gamma + \beta + \delta = 360^\circ$ we have that $\alpha + \gamma = \beta + \delta = 180^\circ$. So $180^\circ = \beta + \delta = 2\alpha + 2\alpha + 40^\circ = 4\alpha + 40^\circ$, from where we obtain $4\alpha = 140^\circ$ i.e. $\alpha = 35^\circ$. Now we get that $\beta = 2\alpha = 70^\circ$, $\gamma = 180^\circ - \alpha = 145^\circ$ and $\delta = 2\alpha + 40^\circ = 2 \cdot 35^\circ + 40^\circ = 110^\circ$.
