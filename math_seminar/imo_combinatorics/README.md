# IMO Combinatorics — research edition

Theory book author: **Ayden Bi**.

Start with [Coverage_Report.md](Coverage_Report.md). The all-history and all-solutions goals are not complete.

- [Combinatorics_Theory.pdf](Combinatorics_Theory.pdf) / [Combinatorics_Theory.md](Combinatorics_Theory.md): proved methods, derived generalizations, 20 exercises with solutions.
- [Worked_Solutions.pdf](Worked_Solutions.pdf) / [Worked_Solutions.md](Worked_Solutions.md): 26 checked rewritten historical cases.
- [Problems_and_Archive_Guide.pdf](Problems_and_Archive_Guide.pdf) / [Problems_and_Archive_Guide.md](Problems_and_Archive_Guide.md): case-study problems without answers, coverage and candidate index.
- [Collected_Problems.pdf](Collected_Problems.pdf) / [Collected_Problems.md](Collected_Problems.md): printable collection of the 770 included source statements.
- [Collected_Source_Problems.md](Collected_Source_Problems.md): 770 full source statements, with attribution.
- problems/: one file per included source statement.
- reviewed_problems/ and reviewed_solutions/: one file per W01–W26.
- source_solutions/: 632 files, 786 supplied solutions; **not independently reviewed**.
- [Catalog.csv](Catalog.csv): all 1116 retrieved candidates, including quarantine and pointer-only records.
- audit/: complete provenance, known defects, exact-duplicate groups, counts and finite verification results.

Mathematics is written in Markdown with LaTeX notation. The PDFs render the authored exposition. No external images are required for the reviewed cases. Some source-language text is not English.

For reuse of imported source text, retain its MathNet and original-source attribution and the CC BY 4.0 notice. Original rights assertions take precedence; those raw texts were withheld. Do not remove the review-status labels.
