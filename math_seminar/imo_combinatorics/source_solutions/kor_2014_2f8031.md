## Supplied solution 1

The implication $(1) \Rightarrow (2)$ is obvious. We prove the converse. Let $G = (V, E)$ be a graph where $V$ is the set of castles and each edge corresponds to a neighboring relation. We set $A = \{v_1, v_2, \dots, v_n\}$. Now let $P_i \subseteq V - A$ be the set of castles whose generals decide to attack castles in $A$. We let $Q_i \subseteq A$ be the set of castles which are either $v_i$ itself or neighboring $v_i$.
Let us consider the list of sets $Q_1$ ($|P_1|$ times), $Q_2$ ($|P_2|$ times), ..., $Q_i$ ($|P_i|$ times), ..., $Q_n$ ($|P_n|$ times). If we choose a collection $Q_{i_1}, Q_{i_2}, \dots, Q_{i_k}$ in this list, we have
$$
|P_{i_1}| + |P_{i_2}| + \dots + |P_{i_k}| \le |Q_{i_1} \cup \dots \cup Q_{i_k}| 
$$
by (2). Therefore, Hall's Marriage Theorem implies that for each $i = 1, 2, \dots, n$, we can choose mutually disjoint $D_1, D_2, \dots, D_n$ such that $|D_i| = |P_i|$ and $D_i \subseteq Q_i$.
$\Box$
