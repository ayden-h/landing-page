## Supplied solution 2

We present another construction of a sequence ( $x_{i}$ ) for part (b).
For each $1 \leq i \leq n$, let
$$
M_{i}=\max \{a_{j}: 1 \leq j \leq i\} \quad \text{ and } \quad m_{i}=\min \{a_{j}: i \leq j \leq n\} .
$$
For all $1 \leq i<n$, we have
$$
M_{i}=\max \{a_{1}, \ldots, a_{i}\} \leq \max \{a_{1}, \ldots, a_{i}, a_{i+1}\}=M_{i+1}
$$
and
$$
m_{i}=\min \{a_{i}, a_{i+1}, \ldots, a_{n}\} \leq \min \{a_{i+1}, \ldots, a_{n}\}=m_{i+1} .
$$
Therefore sequences ( $M_{i}$ ) and ( $m_{i}$ ) are non-decreasing. Moreover, since $a_{i}$ is listed in both definitions,
$$
m_{i} \leq a_{i} \leq M_{i}
$$
To achieve equality in (1), set
$$
x_{i}=\frac{M_{i}+m_{i}}{2}
$$
Since sequences ( $M_{i}$ ) and ( $m_{i}$ ) are non-decreasing, this sequence is non-decreasing as well.
From $d_{i}=M_{i}-m_{i}$ we obtain that
$$
-\frac{d_{i}}{2}=\frac{m_{i}-M_{i}}{2}=x_{i}-M_{i} \leq x_{i}-a_{i} \leq x_{i}-m_{i}=\frac{M_{i}-m_{i}}{2}=\frac{d_{i}}{2}
$$
Therefore
$$
\max \{\left|x_{i}-a_{i}\right|: 1 \leq i \leq n\} \leq \max \{\frac{d_{i}}{2}: 1 \leq i \leq n\}=\frac{d}{2}
$$
Since the opposite inequality has been proved in part (a), we must have equality.
