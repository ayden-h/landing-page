## Supplied solution 1

(i) The triple $(10, 0, 0)$ can be made only when $a_1$ wins exactly $10$ times, and $(0, 10, 0)$ is only when $b_1$ wins $10$ games. The number of games that a player $x \notin \{a_1, b_1\}$ can win is strictly less than $10$. Therefore, the number of possible triples $(P_A, P_B, P_C)$ is exactly the same as the number of different processes of the tournament.

(ii) Let $f(l, m, n)$ be the number of possible triples $(P_A, P_B, P_C)$ when $l$, $m$, $n$ students from schools $A$, $B$, $C$, respectively, participate in the tournament. Two possible results of the first match will give us the following:
$$
f(l, m, n) = f(n, m, l-1) + f(l, n, m-1).
$$
If there is no player left for a school, then we have a binomial number, and we have
$$
f(l, m, 0) = \binom{l+m}{m} \qquad f(l, m, n) = 0 \quad \text{if } n < 0.
$$
Moreover, we have $f(l, m, n) = f(m, l, n)$.
Since the number we are looking for is $f(5, 5, 5)$, let us consider the number $f(n, n, n)$:
$$
f(n, n, n) = 2f(n, n, n-1) \\
f(n, b, k) = f(k, n, n-1) + f(n, k, n-1) = 2f(n, k, n-1) \\
f(n, n, n) = 4f(n, n-1, n-1).
$$
Therefore, the remainder of $f(5, 5, 5)$ divided by $8$ is $4$ if $f(5, 4, 4)$ is odd and $0$ if $f(5, 4, 4)$ is even.

(iii) Let us calculate $f(5, 4, 4)$ modulo $2$.
$$
\begin{align*}
& f(5, 4, 4) \\
= & f(4, 4, 4) + f(5, 4, 3) \\
= & 0 + f(3, 4, 4) + f(5, 3, 3) \\
= & f(4, 4, 2) + f(3, 4, 3) + f(3, 3, 4) + f(5, 3, 2) \\
= & 0 + f(3, 4, 3) + 0 + f(5, 3, 2) \\
= & f(3, 4, 2) + f(3, 3, 3) + f(2, 3, 4) + f(5, 2, 2) \\
= & f(3, 4, 2) + 0 + f(2, 3, 4) + f(5, 2, 2) \\
= & f(2, 4, 2) + f(3, 2, 3) + f(4, 3, 1) + f(2, 4, 2) + f(2, 2, 4) + f(5, 2, 1) \\
= & f(3, 2, 3) + f(4, 3, 1) + f(5, 2, 1) \\
= & f(3, 2, 2) + f(3, 3, 1) + f(1, 3, 3) + f(4, 1, 2) + f(1, 2, 4) + f(5, 1, 1) \\
= & f(3, 2, 2) + 0 + f(1, 3, 3) + f(4, 1, 2) + f(1, 2, 4) + f(5, 1, 1) \\
= & f(2, 2, 2) + f(3, 2, 1) + f(3, 3, 0) + f(1, 3, 2) + f(2, 1, 3) + f(4, 2, 0) \\
& + f(4, 2, 0) + f(1, 4, 1) + f(1, 1, 4) + f(5, 1, 0) \\
= & 0 + f(3, 2, 1) + 0 + f(1, 3, 2) + f(2, 1, 3) + 0 + 0 + f(1, 4, 1) + 0 + 0 \\
= & f(1, 2, 2) + f(3, 1, 1) + f(2, 3, 0) + f(1, 2, 2) + f(3, 1, 1) + f(2, 3, 0) \\
& + f(1, 4, 0) + f(1, 1, 3) \\
= & f(1, 4, 0) = 1
\end{align*}
$$
$f(5, 4, 4)$ is odd and the answer is $4$.
