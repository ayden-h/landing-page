# W18. Keeping 150 entries of a doubly stochastic matrix

**Source:** China TST 2023, Test Three, Day 2, Problem 6. **Record:** `chn_2023_a44cf5`.

In any nonnegative \(100\times100\) matrix with every row sum and column sum equal to one, retain 150 entries and set the others to zero. What is the largest universal lower bound \(\lambda\) on all remaining row and column sums?
