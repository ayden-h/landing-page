# W13. Fifteen subsets of a 56-element set

**Source:** China Mathematical Olympiad 2006, Problem 6, attributed to Leng Gangsong. **Record:** `chn_2006_c22bc5`.

Find the smallest integer \(N\) such that, if every seven of fifteen subsets of a 56-element set have union of size at least \(N\), some three subsets have a common element.
