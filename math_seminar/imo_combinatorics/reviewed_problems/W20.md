# W20. Unique subsums with odd parts

**Source:** India IMO TST 2013, Problem 3. **Record:** `ind_2013_5ef73e`.

A partition of 9999 into odd positive parts is called sum-friendly if each integer from 0 to 9999 has exactly one subsum representation. Equal copies of a part are indistinguishable: a representation specifies only how many copies of each distinct value are used. Count the sum-friendly partitions.
