# W26. Reducing a set by sum-and-difference moves

**Source:** RMM 2021, Problem 4. **Record:** `rmm_2021_03b2ae`.

Start with \(\{1,2,\ldots,n\}\), \(n\ge2\). Erase two distinct current numbers \(a,b\), and insert \(a+b\) and \(|a-b|\), suppressing any duplicate with an existing number. Can the set be reduced to exactly two elements?
