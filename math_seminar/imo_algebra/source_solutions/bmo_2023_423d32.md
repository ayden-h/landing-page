## Supplied solution 1

Answer: $f(x) = 0$ for all real numbers $x$ or $f(x) = x$ for all real numbers $x$.
Let $P(x, y)$ be the assertion of the given equation. We will consider two cases:

**Case 1.** Function is not periodic. This means that if $f(x + p) = f(x)$ for every real number $x$, then $p = 0$.
Considering $P(1, x - 1)$ we have $f(x - 1 + f(1)) = f(x)$ hence $-1 + f(1) = 0 \implies f(1) = 1$. Taking $P(-1, x + 1)$, we have $f(-x - 1 + f(1)) = -f(x) \implies f(-x) = -f(x)$, so the function is odd and $f(0) = 0$. We now prove a converse to the last equality.

*Claim.* $f(a) = 0$ implies $a = 0$.
*Proof.* Suppose, for contradiction, that $a \neq 0$. Since the function is odd, we can assume $a > 0$. Then taking $P(\sqrt{a}, x + \sqrt{a})$ we have,
$$
f(\sqrt{a}(x + \sqrt{a}) + f(a)) = \sqrt{a} f(\sqrt{a} + x + \sqrt{a}) \implies \frac{f(\sqrt{a} x + a)}{\sqrt{a}} = f(x + 2\sqrt{a}).
$$
Similarly taking $P(-\sqrt{a}, x + \sqrt{a})$ and using that function is odd we have,
$$
\begin{aligned}
f(-\sqrt{a}(x + \sqrt{a})) &= f(-\sqrt{a}(x + \sqrt{a}) + f(a)) = -\sqrt{a} f(-\sqrt{a} + x + \sqrt{a}) = -\sqrt{a} f(x) \\
&\implies \frac{f(\sqrt{a} x + a)}{\sqrt{a}} = f(x).
\end{aligned}
$$
From last two relations we have that for every real number $x$, the equality $f(x + 2\sqrt{a}) = f(x)$ holds and hence $2\sqrt{a} = 0 \implies a = 0$, thus we get a contradiction. $\square$

As $f(a) = 0 \iff a = 0$, taking $P(x, -x)$ for every real number $x$ we have,
$$
f(-x^2 + f(x^2)) = x f(0) = 0 \implies -x^2 + f(x^2) = 0 \implies f(x^2) = x^2.
$$
As the function is odd we get $f(x) = x$ for all real numbers $x$ which clearly is a solution.

**Case 2.** Function is periodic. Then there exists a real number $p \neq 0$ such that $f(x + p) = f(x)$ for all real numbers $x$.
We have $f(x + y + p) = f(x + y)$ for all real numbers $x, y$. $P(x, y)$ and $P(x, y + p)$ give
$$
f(xy + f(x^2)) = x f(x + y) = x f(x + y + p) = f(xy + x p + f(x^2)).
$$
Let $a \neq b$ be any two real numbers. Letting $x = \frac{b-a}{p}$ and $y = \frac{a-f(x^2)}{x}$ in the equation above yields $f(a) = f(b)$. Hence the function is constant and from the condition $f(0) = 0$, we find that only $f(x) = 0$ for all real numbers $x$ satisfies the condition.

In conclusion all functions which satisfy the condition are $f(x) = x$ for all real numbers $x$ or $f(x) = 0$ for all real numbers $x$.
