## Supplied solution 1

Answer: $f(x) = x$ for all $x \in \mathbb{R}_{>0}$. We first show that $f$ is bijective.
* $f$ is injective since $f(y_1) = f(y_2)$ implies
$$f(x^{2023} + f(x)f(y_1)) = f(x^{2023} + f(x)f(y_2)) \implies x^{2023} + y_1f(x) = x^{2023} + y_2f(x),$$ 
hence $y_1 = y_2$.
* $f$ is surjective since for any positive $s$, considering some positive $x$ with $x^{2023} < s$ and letting $y = \frac{s-x^{2023}}{f(x)}$, one obtains $f(x^{2023} + f(x)f(y)) = s$.
Now we define $g(t) := (f^{-1}(t))^{2023}$ and rewrite the original equation replacing $x$ by $f^{-1}(t)$ and $y$ by $f^{-1}(x)$:
$$
f(tx + g(t)) = tf^{-1}(x) + g(t).
$$
Replacing $x$ by $f(x)$ and applying $f^{-1}$ on both sides, one finds that the roles of $f$ and $f^{-1}$ can be switched:
$$
f^{-1}(tx + g(t)) = tf(x) + g(t).
$$
Successively applying the last two equations, one obtains
$$
f(t_1t_2x + t_1g(t_2) + g(t_1)) = t_1f^{-1}(t_2x + g(t_2)) + g(t_1) = t_1t_2f(x) + t_1g(t_2) + g(t_1). \quad (\text{A6-1})
$$
Plugging in $t_1 = t_2 = 1$ in (A6-1), one gets
$$
f(x + 2g(1)) = f(x) + 2g(1). \qquad (\text{A6-2})
$$
Moreover, plugging in $t_1 = t$, $t_2 = 1$ and $t_1 = 1$, $t_2 = t$ in (A6-1), one gets the two equations
$$
f(tx + tg(1) + g(t)) = tf(x) + tg(1) + g(t), \quad f(tx + g(1) + g(t)) = tf(x) + g(1) + g(t). \quad (\text{A6-3})
$$
Considering any sufficiently large $y$, one can substitute $x = \frac{y-(g(1)+g(t))}{t}$ in (A6-3) and subtract the second equation from the first one, thus finding
$$
f(y + (t - 1)g(1)) - f(y) = (t - 1)g(1).
$$
Now let $x$ and $c$ be arbitrary positive real numbers, let $t = 1 + \frac{c}{g(1)}$ so that $c = (t - 1)g(1)$, and let $y = x + 2Ng(1)$ where $N$ is a sufficiently large positive integer. Then, using (A6-2) and the last equation, we get
$$
f(x + c) - f(x) = f(y + c) - f(y) = c.
$$
Consequently, $f(x) - x$ is a constant whose value is easily determined to be 0 by, for example, using (A6-3) or considering the bijectivity of $f$.
The only solution is $f(x) = x$ for all $x \in \mathbb{R}_{>0}$, which clearly satisfies the condition.
**Remark.** We can interchange $x^{2023}$ by any function $h: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$ which can take arbitrarily small positive values, and the same solution works.
