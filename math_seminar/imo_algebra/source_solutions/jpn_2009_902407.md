## Supplied solution 1

[9996]

Note that $n^2 + 4n = (n + 2)^2 - 4$ and that if $m < n$, then $m^2 + 4m < n^2 + 4n$.

Since $100^2 = 10000$, we see that the desired solution is either $100^2 - 4 = 9996$ or $101^2 - 4 = 10197$, whichever has the smaller difference (in absolute value) from $10000$. So, the answer is $9996$.
