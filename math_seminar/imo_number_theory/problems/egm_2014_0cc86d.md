## Problem

Determine all integers $n \geq 2$ for which there exist integers $x_{1}, x_{2}, \ldots, x_{n-1}$ satisfying the condition that if $0 < i < n$, $0 < j < n$, $i \neq j$ and $n$ divides $2i + j$, then $x_{i} < x_{j}$.
