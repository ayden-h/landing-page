Taking the sum and the difference of the corresponding sides of the given 2 equations, we obtain, respectively
$$
(ab + c) + (a + bc) = (b + 1)(a + c) = 36
$$
$$
(a + bc) - (ab + c) = (b - 1)(c - a) = 10
$$
Since both $a$ and $c$ are positive integers, we see that $b+1$, $b-1$ are factors of $36$, $10$, respectively. From this fact, we can conclude that only possible values of $b$ are $2$, $3$, $11$.

If $b = 3$, we obtain by solving the simultaneous equations $a + c = 9$, $c - a = 5$ that $(a, b, c) = (2, 3, 7)$.

If $b = 11$, we obtain by solving the simultaneous equations $a + c = 3$, $c - a = 1$ that $(a, b, c) = (1, 11, 2)$.
