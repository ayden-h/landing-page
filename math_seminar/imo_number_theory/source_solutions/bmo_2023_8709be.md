## Supplied solution 1

We denote $x^2 = a + bc$, $y^2 = b + ca$, $z^2 = c + ab$. We make use of the following well-known lemma:

*Lemma.* A positive integer $n$ can be written as the sum of two squares if and only if for all primes $p \equiv 3 \pmod{4}$, $v_p(n)$ is even.

Note that we can write the target expression as:
$$
S = a^2(b+c) + b^2(c+a) + c^2(a+b) + 2abc = (a+b)(b+c)(c+a)
$$
By the Lemma, it is sufficient to prove $v_p(S)$ is even for all primes $p \equiv 3 \pmod{4}$. We claim the stronger statement that $v_p(a+b)$ is even (and cyclic variations) for all such primes.

Let $p \equiv 3 \pmod{4}$ be prime with $v_p(a+b) > 0$. Then observe:
$$
x^2 + y^2 = (a+b)(c+1) \equiv 0 \pmod{p}
$$
As $p \equiv 3 \pmod{4}$, $\binom{-1}{p} = -1$, this means $p \mid x, y$. We claim that $c \not\equiv -1 \pmod{p}$. Indeed, if $c \equiv -1 \pmod{p}$ then by the above:
$$
0 \equiv x^2 = a + bc \equiv a - b \pmod{p}
$$
As $p \mid a+b$, this means $p \mid 2a$ and hence $p \mid a$ (as $p \neq 2$). But then we would have:
$$
z^2 = c + ab \equiv c \equiv -1 \pmod{p}
$$
which cannot happen as $\binom{-1}{p} = -1$. Thus $p \nmid c+1$ and hence using $p \equiv 3 \pmod{4}$ and the Lemma:
$$
0 \equiv v_p(x^2 + y^2) = v_p((a+b)(c+1)) = v_p(a+b) + \underbrace{v_p(c+1)}_{=0} = v_p(a+b) \pmod{2}
$$
which proves the claim.
